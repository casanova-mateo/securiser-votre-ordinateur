# Sécuriser votre ordinateur personnel

Guide pratique gratuit pour protéger vos données sous Windows, macOS et Linux, sans connaissances techniques, avec trois fiches à imprimer.

**Site : <https://casanova-mateo.github.io/securiser-votre-ordinateur/>**

Par Matéo CASANOVA · Version 1.0 (version originale en français) · Octobre 2026

Le guide se lit en ligne, page par page : <https://casanova-mateo.github.io/securiser-votre-ordinateur/guide/>

## Télécharger

| Document | Contenu |
|---|---|
| [Le guide (PDF, 27 pages)](securiser-votre-ordinateur-personnel.pdf) | Mises à jour, antivirus, mots de passe, chiffrement du disque, comptes en ligne, navigation, réseau, sauvegardes, smartphone, Linux, que faire en cas de problème, liste de vérification |
| [Fiche 1 — Bien démarrer](fiches/fiche-1-bien-demarrer.pdf) | Les mesures essentielles, le kit de secours et la liste de vérification |
| [Fiche 2 — Les bons réflexes](fiches/fiche-2-bons-reflexes.pdf) | Reconnaître les arnaques et les pièges les plus courants |
| [Fiche 3 — En cas d'urgence](fiches/fiche-3-en-cas-d-urgence.pdf) | Que faire en cas de virus, de piratage ou de fraude bancaire |

Chaque fiche tient sur une feuille recto-verso. Les versions précédentes restent disponibles dans les [Releases](https://github.com/casanova-mateo/securiser-votre-ordinateur/releases).
